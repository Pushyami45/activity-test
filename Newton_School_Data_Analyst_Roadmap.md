# Newton School Data Analyst Course - Progress Tracker & Roadmap

Welcome to your Data Analytics journey! You can use this file to track your progress through the Newton School Data Analyst course.

## 🚀 Phase 1: Foundations (Excel & Statistics)
- [ ] **Excel Basics to Advanced**:
  - Formulas, VLOOKUP/HLOOKUP, XLOOKUP
  - Pivot Tables and Dashboards
  - Data Cleaning (Power Query)
- [ ] **Statistics & Math for Data**:
  - Descriptive Statistics (Mean, Median, Mode, Variance, Standard Deviation)
  - Inferential Statistics (Hypothesis Testing, A/B Testing, p-values)

## 🗄️ Phase 2: Database Management (SQL)
- [ ] **SQL Fundamentals**:
  - CRUD operations (Select, Insert, Update, Delete)
  - Filtering and Sorting (WHERE, ORDER BY, GROUP BY, HAVING)
- [ ] **Advanced SQL**:
  - Joins (Inner, Left, Right, Full)
  - Subqueries and CTEs (Common Table Expressions)
  - Window Functions (RANK, DENSE_RANK, ROW_NUMBER)

- [ ] **Python Basics**:
  - Variables, Data Types, Loops, Functions

- [ ] **Data Visualization**:
  - Matplotlib & Seaborn (Bar charts, scatter plots, heatmaps)

- [ ] **Connecting & Transforming Data**:
  - Importing data from various sources
  - Data Modeling (Star Schema)
- [ ] **Data Visualization & Dashboards**:
